# Practice website

Small production site for one independent practice. This repository currently contains the Next.js scaffold, project rules, and architecture notes. Booking, payments, and calendar behaviour are specified in `docs/ARCHITECTURE.md` and are not built yet.

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` when credentials exist. Use test keys only during development. Do not deploy from this phase.

- Architecture: `docs/ARCHITECTURE.md`
- Decisions to confirm: `docs/DECISIONS.md`
- Known issues: `docs/KNOWN_ISSUES.md`
